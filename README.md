# 🎓 UNITEN Campus Hub - DevStart Mini Hackathon Mockup

## 📌 Problem Statement
UNITEN students frequently switch between multiple platforms to keep up with campus events, library resources, and group tasks.

## 💡 Solution
**UNITEN Campus Hub** centralizes essential student resources into one simple, fast-loading dashboard.

## ✨ Features
- **Upcoming Events:** Key dates for hackathons, workshops, and study sessions.
- **Quick Links:** One-click access to essential campus sites.
- **Project Overview:** A baseline prototype designed for rapid iteration.

## 🛠️ Built With
- HTML5 & CSS3
- Hosted on GitHub Pages
